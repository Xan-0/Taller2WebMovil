# Taller2WebMovil -> Talleres 2 y 3
Gestor de Tareas diarias y Eventos en AngularTS, Python FastAPI y PostgreSQL
- Deploy mediante Railway y Capacitor
<br>

# Ejecución:
- *Base de datos:* Instalando PostgreSQL localmente y creando la base de datos **taller2_WM_db**.

- *Back-end*: Ejecutando FastAPI con Uvicorn en tu entorno virtual de Python (creado con el **environment.yml**).

- *Front-end:* Ejecutando `npm install` y `ng serve` de Angular en tu terminal.

Más información en backend/README.md y frontend/README.md
