# Taller2WebMovil
Gestor de Tareas simple en AngularTS, Python FastAPI y PostgreSQL

# Ejecución futura planeada:
- Base de datos: Instalando PostgreSQL localmente y creando la base de datos *taller2_WM_db*.
- Back-end: Ejecutando FastAPI con Uvicorn en tu entorno virtual de Python (creado con el *environment.yml*).
- Front-end: Ejecutando `ng serve` de Angular en tu terminal.
